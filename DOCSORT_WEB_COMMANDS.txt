DOCSORT - WEB APP ONLY
Location: D:\Projects\DocSort

==================================================
TERMINAL 1 - START BACKEND
==================================================

cd D:\Projects\DocSort\docsort-backend
.venv\Scripts\python.exe -m uvicorn app.main:app --reload --reload-exclude ".venv/*" --port 8000


Keep Terminal 1 running.

Backend:
http://127.0.0.1:8000

API Docs:
http://127.0.0.1:8000/docs

Ready Check:
http://127.0.0.1:8000/ready


==================================================
TERMINAL 2 - START FLUTTER WEB APP
==================================================

cd D:\Projects\DocSort\docsort
flutter pub get
flutter run -d chrome --web-port 3000 --dart-define=API_BASE_URL=http://127.0.0.1:8000


Web App:
http://localhost:3000


==================================================
STOP THE APP
==================================================

Press Ctrl+C in Terminal 2 to stop Flutter.

Press Ctrl+C in Terminal 1 to stop the backend.
