# Security Policy

## Supported release

The current `1.0.x` project line is the supported source snapshot for this academic project.

## Reporting a vulnerability

Please do not publish suspected credentials or exploitable security details in a public issue. After the repository is hosted on GitHub, use the repository's private security-advisory / private vulnerability-reporting channel when available, or contact the repository maintainer privately.

Include the affected path/endpoint, reproduction conditions, expected impact, and whether real data or credentials may have been exposed. Do not include live secrets in the report; rotate any exposed credential immediately.
